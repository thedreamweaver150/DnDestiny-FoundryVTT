# Settings

World settings added by this system, found under **Game Settings → Configure Settings → Dungeons & Destiny**. All are world-scoped (GM-only, affect every player).

| Setting | Default | Effect |
|---|---|---|
| **Hide Spells Tab** | On | Hides the Spells tab on character sheets. Light Abilities live on their own Core Light Abilities tab regardless (see [Light & Abilities](light-and-abilities.md)); this just hides the now-redundant native tab. |
| **Hide Hit Dice** | On | Hides Hit Dice everywhere: the character sheet, a class item's Hit Dice field, and the Short Rest dialog. Reserved for a future dedicated character sheet that replaces it with Shields' own die mechanic. |
| **Track Weapon Ammo** | On | Enables magazine size / shots-remaining tracking and the Reload activity for Shot Capacity weapons. Off treats Shot Capacity as purely descriptive text. See [Ammo & Reloading](ammo-and-reloading.md). |
| **Show Base D&D Special Traits** | Off | The Special Traits tab hides dnd5e's native Feats/Racial Traits/Global Bonuses fieldsets by default, leaving just this system's own "Jack of all Guns" trait. Enable to show the native ones again alongside it. |

Toggling any of these immediately re-renders every open Actor/Item sheet so the change is reflected without needing to close and reopen anything.
